Purchase Functions — အသုံးပြုပုံလမ်းညွှန်

ဝယ်ယူမှု (Purchase Voucher, Purchase Order, Payment, Budget, Excel Import, FEFO)
ရက်စွဲ — ၂၅ ဩဂုတ် ၂၀၂၆  |  ပစ်မှတ်အသုံးပြုသူ — စတော့ / ဝယ်ယူရေး / ငွေစာရင်း ဝန်ထမ်း

၁။ ဘယ်နေရာက စမလဲ

ဘယ်ဘက်မီနူး → Purchases ကို နှိပ်ပါ။ ဖွင့်ရင် စာမျက်နှာ နှစ်ပိုင်း ဖြစ်သည်။

  • ဘယ် (~၈၀%) — voucher ဇယား (ကုဒ်၊ ရက်စွဲ၊ ပေးသွင်းသူ၊ ပမာဏ၊ ငွေပေးချေမှု အခြေအနေ)
  • ညာ (~၂၀%) — ခလုတ်များ၊ စုစုပေါင်း ကိန်းဂဏန်း၊ ဂရပ်၊ ရှာဖွေ / စစ်ထုတ်

ဖုန်း / မျက်နှာပြင် ကျဉ်းရင် ဇယား အပေါ်၊ ခလုတ်များ အောက် ဖြစ်သည်။

၂။ ဝယ်ယူမှုအသစ် (New Purchase)

  1. ညာဘက် New Purchase ကို နှိပ်ပါ။
  2. ပေးသွင်းသူ (Supplier) ရွေးပါ။
  3. Warehouse ထည့်ပါ (ရှိရင်)။
  4. လိုအပ်ရင် Supplier Invoice # ထည့်ပါ။ တူညီတဲ့ နံပါတ် ရှိပြီးသားဆိုရင် စနစ်က သတိပေးသည်။
  5. ငွေကြေး Currency ရွေးပါ။ နိုင်ငံခြားငွေဆိုရင် နှုန်း (rate) ထည့်ပါ။
  6. အခွန်ပုံစံ ရွေးပါ — Exclusive (ဈေးပေါ် အခွန်ထပ်) သို့ Inclusive (ဈေးထဲ အခွန်ပါပြီး)။
  7. WHT လိုအပ်ရင် ရာခိုင်နှုန်း ထည့်ပါ။
  8. ကုန်စည် ပို့ဆောင်ခ / အကောက်ခွန် စသည့် Landed Cost ရှိရင် ထည့်ပြီး ခွဲဝေပုံ ရွေးပါ (တန်ဖိုးအချိုး / အရေအတွက်အချိုး / ကိုယ်တိုင်)။
  9. ကုန်ပစ္စည်းများ ထည့်ပါ — ကုန်၊ အရေအတွက်၊ ယူနစ်ဈေး၊ လိုအပ်ရင် သက်တမ်းကုန်ရက် / လော့နံပါတ်။
  10. ငွေပေးချေမည်ဆိုရင် ငွေပေးနည်း ရွေးပါ။ ယခုမပေးရင် ကြွေးကျန် ဖြစ်သည်။
Save vs Confirm
Save Draft — မူကြမ်းသာ။ စတော့ မတက်သေး။ ပြင်နိုင်သည်။
Confirm — အတည်ပြု။ စတော့ တက်သည်။ Journal ကျသည်။ ပြီးရင် တိုက်ရိုက် မပြင်ရ။

၃။ Excel မှ တင်သွင်းခြင်း

  1. ညာဘက် Template ကို နှိပ်ပြီး နမူနာ ဖိုင် ဆွဲယူပါ။
  2. Excel ထဲမှာ ပေးသွင်းသူ၊ ကုန်ကုဒ်၊ အရေအတွက်၊ ဈေး ဖြည့်ပါ။
  3. Excel Import နှိပ်ပြီး ဖိုင် ရွေးပါ။ အများဆုံး ၅ MB။
  4. ကြိုကြည့် ဇယား ပေါ်လာသည်။ အမှားရှိတဲ့ အတန်းကို ပြင်ပြီး ပြန်တင်ပါ။
  5. အိုကေမှသာ ဖောင်ထဲ ဝင်သည်။ ထိုအချိန်မှာ စတော့ မတက်သေး။
  6. ဖောင် စစ်ပြီး Confirm မှသာ စတော့ တက်သည်။
Excel ဖိုင် တင်တာနဲ့ ချက်ချင်း မဝယ်သေးပါ။ Confirm လုပ်မှသာ ဝယ်ယူမှု ပြီးသည်။

၄။ အခွန်၊ WHT၊ ပို့ဆောင်ခ၊ ငွေကြေး

အကြောင်းအရာလုပ်ရမည်
Tax Exclusiveယူနစ်ဈေးပေါ် VAT/အခွန် ထပ်တွက်သည်။
Tax Inclusiveယူနစ်ဈေးထဲ အခွန်ပါပြီး။ စနစ်က ခွဲထုတ်သည်။
WHTရာခိုင်နှုန်း ထည့်ရင် ပေးရန်ငွေမှ နုတ်သည်။
Landed Costပို့ဆောင်ခ စသည် ဖြန့်ဝေပြီး ကုန်ကျစရိတ်ထဲ ထည့်သည်။
နိုင်ငံခြားငွေငွေကြေး + နှုန်း ထည့်ပါ။ နောက်မှ နှုန်း မပြောင်းပါ။

၅။ ဘတ်ဂျက် (Budget)

  1. ညာဘက် Budgets နှိပ်ပါ။
  2. ပေးသွင်းသူ / အမျိုးအစား / ကာလ / ကန့်သတ်ပမာဏ ထည့်ပါ။
  3. ကျော်သွားရင် လုပ်ဆောင်ချက် ရွေးပါ — WARN (သတိပေး၊ ဆက်သိမ်းနိုင်) သို့ BLOCK (မသိမ်းရ)။
BLOCK ကျော်ရင် Confirm မရပါ။ ဘတ်ဂျက် တိုးပါ၊ သို့မဟုတ် ကြီးကြပ်သူကို ပြောပါ။

၆။ ပေးသွင်းသူအား ငွေပေးခြင်း

ညာဘက် Payment နှိပ်ပါ။

၆.၁ ကြွေးကျန် ရှင်းခြင်း

  1. ပေးသွင်းသူ ရွေးပါ။
  2. ပမာဏ + ငွေပေးနည်း + ရက်စွဲ ထည့်ပါ။
  3. FIFO — အဟောင်းဆုံး ကြွေးက စရှင်းသည်။ Manual — voucher တစ်ခုချင်း ခွဲထည့်သည်။
  4. Save လုပ်ပါ။ ငွေထွက် journal ကျသည်။

၆.၂ ကြိုပေးငွေ (Advance)

ကြွေးမရှိသေးဘဲ ကြိုပေးရင် Advance ဖြစ်သည်။ နောက် voucher မှာ Apply Credit နှိပ်ပြီး SCA ကုဒ်နဲ့ ချိတ်ပါ။

ငွေပေးပြီး voucher ကို တိုက်ရိုက် ဖျက်လို့ မရပါ။ ငွေပေးမှတ်တမ်း ရှိနေလို့ ဖြစ်သည်။

၇။ Voucher ကူးယူခြင်း (Copy)

ဇယားထဲ voucher ကို ဖွင့် → Copy Voucher။ ပေးသွင်းသူ / ကုန်စာရင်း ကူးသည်။ ရက်စွဲ / ငွေပေးအခြေအနေ အသစ် ဖြစ်သည်။ စစ်ပြီးမှ Confirm ပါ။

၈။ FEFO / သက်တမ်းကုန်

  • ဝယ်တဲ့အခါ Expiry Date ထည့်ပါ။
  • ရောင်းတဲ့အခါ သက်တမ်းနီးတာ အရင် ထွက်သည် (FEFO)။
  • ညာဘက် Expiry နှိပ်ပြီး သက်တမ်းနီး / ကုန်ပြီး ကုန်များကို ကြည့်ပါ။

၉။ Warehouse နှင့် Analytics

  • Warehouse — ဂိုဒေါင်အလိုက် လက်ကျန် (warehouse name အလိုက်)။
  • Analytics — ပေးသွင်းသူ / အမျိုးအစား / ငွေကြေး အလိုက် ဝယ်ယူမှု။
  • Voucher ဖွင့်ရင် Activity Timeline — ဝယ်၊ ငွေပေး၊ ကြိုငွေချိတ်၊ ပြန်ပို့၊ GRN စသည့် အဆင့်များ။

၁၀။ Purchase Order (PO) နှင့် ကုန်လက်ခံ (GRN)

  1. မီနူး → Purchase Orders။
  2. PO အသစ် → ပေးသွင်းသူ + ကုန်စာရင်း → Submit / Approve။
  3. ကုန်ရောက်ရင် Receive။
  4. အရေအတွက် မှန်ရင် MATCHED၊ မမှန်ရင် VARIANCE။ ပျက်စီး / ငြင်းပယ် အရေအတွက် မှတ်ပါ။
  5. Receive ပြီးရင် Purchase Voucher ဖြစ်လာပြီး စတော့ တက်သည်။
  6. PO ဖွင့်ကြည့်ရင် အောက်မှာ GRN မှတ်တမ်း ရှိသည်။

၁၁။ စာရင်းပိတ်ကာလ (Period Lock)

Accounting Dashboard မှ ကာလ ပိတ်နိုင်သည်။ ပိတ်ထားသော လအတွင်း ဝယ်ယူမှု အသစ် / ငွေပေး အသစ် မလုပ်ရ။ မှားသွားရင် ကြီးကြပ်သူက ကာလ ပြန်ဖွင့်မှ ပြင်နိုင်သည်။

၁၂။ နေ့စဉ် လုပ်ငန်းစဉ် (အတို)

  1. ကုန်ရောက် → New Purchase (သို့) PO Receive။
  2. Invoice # / အခွန် / ပို့ဆောင်ခ စစ်ပါ။
  3. Draft သိမ်း → စစ် → Confirm။
  4. ငွေပေးချိန်ရင် Payment မှ ရှင်းပါ။
  5. သက်တမ်းနီးကုန် Expiry ကြည့်ပါ။
  6. လကုန်ရင် Analytics / ငွေစာရင်း စစ်ပြီး Period Lock။
