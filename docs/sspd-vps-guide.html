၈။ systemd service

ဖိုင်: /etc/systemd/system/sspd.service

[Unit] Description=SSPD Service Management After=network.target mysql.service mariadb.service [Service] Type=simple User=sspd Group=sspd WorkingDirectory=/opt/sspd EnvironmentFile=/opt/sspd/.env ExecStart=/usr/bin/java -Dspring.profiles.active=prod -jar /opt/sspd/pos.war SuccessExitStatus=143 Restart=on-failure RestartSec=10 [Install] WantedBy=multi-user.target
systemctl daemon-reload systemctl enable --now sspd systemctl start sspd systemctl stop sspd systemctl restart sspd systemctl status sspd

၉။ Log ကြည့်နည်း

WAR အသစ်တင်ပြီး error ရှိ/မရှိ စစ်ရန် အကောင်းဆုံး:

sudo journalctl -u sspd -f

Log ဆက်တိုက်ပေါ်မည်။ ပြန်ထွက်ရန် Ctrl + C။

နောက်ဆုံး ၁၀၀ ကြောင်း:

sudo journalctl -u sspd -n 100

၁၀။ Nginx + SSL

DNS A Record မှန်ပြီးမှ ဤအဆင့်ကို လုပ်ပါ။ YOUR_DOMAIN နေရာတွင် တကယ့် domain ထည့်ပါ။

apt -y install nginx nano /etc/nginx/sites-available/sspd

အဓိက အချက်များ:

  • Port 80 → HTTPS သို့ ပြန်ညွှန်း
  • Port 443 → proxy_pass http://127.0.0.1:8080
  • /ws-clinic/ နှင့် /ws-native/ တွင် WebSocket upgrade
  • client_max_body_size 200M; (APK upload)
ln -sf /etc/nginx/sites-available/sspd /etc/nginx/sites-enabled/sspd rm -f /etc/nginx/sites-enabled/default nginx -t systemctl reload nginx certbot --nginx -d YOUR_DOMAIN -d www.YOUR_DOMAIN
Certbot မအောင်ရင် အများအားဖြင့် DNS A Record မမှန်ခြင်း သို့မဟုတ် port 80 ကို firewall ပိတ်ထားခြင်း ဖြစ်သည်။ ufw allow 80,443/tcp နှင့် nslookup ပြန်စစ်ပါ။

၁၅။ အမြန် checklist (VPS အသစ်)

  • PEM ကို D:\ssh တွင် သိမ်းပြီး SSH ဝင်နိုင်
  • Java 17, Nginx, MySQL တပ်ပြီး
  • ser_db နှင့် DB user ဖန်တီးပြီး
  • /opt/sspd/.env ပြည့်ပြီး chmod 600
  • pos.war တင်၊ chown sspd:sspd
  • systemctl enable --now sspd → active (running)
  • DNS A Record @ နှင့် www → VPS IP
  • Nginx + certbot HTTPS
  • APP_BASE_URL / CORS ကို https://domain
  • Create Administrator သို့မဟုတ် ရှိပြီးသား admin login
  • journalctl -u sspd -f တွင် error မရှိ
နောက် VPS အသစ် ဤစာအုပ်ကို reference အဖြစ် သုံးပါ။ IP, domain, pem ဖိုင်အမည်သာ လဲပါ။ Password နှင့် JWT ကို စက်အသစ်တိုင်း အသစ်ထုတ်ပါ။
